# Hybrid PLS animation

Restored **original slide visuals** (motivation → 1/4 → 2/4 → 3/4 → 4/4).

Driven by **one continuous clock**:
- `play` / `hold` use the same drawers as before (`instant: true` on holds = exact final frame)
- `morph` segments connect holds without restarting the next slide from scratch

Open `index.html`.
